# crcon.cloud

One-click cloud hosting for [CRCON](https://github.com/MarechJ/hll_rcon_tool),
the community RCON tool for Hell Let Loose.

This repo hosts:

- [`template/`](template/): the Railway deployment template. The custom
  frontend image, the full template composer recipe
  ([TEMPLATE.md](template/TEMPLATE.md)), and the multi-server runbook
  ([EXPANDING.md](template/EXPANDING.md)).
- The crcon.cloud website and docs (coming soon).
